# Changelog - v3.0.0

All notable changes to the `law-scrapper-mcp` project for version v3.0.0 will be documented in this file.

The format is based on [Keep a Changelog 1.1.0](https://keepachangelog.com/en/1.1.0/),
and this project adheres to [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html).

## [v3.0.0] - 2026-08-14

### Added

- **`PageInfo` pagination metadata** — Paginated tool responses include `page_info` with `limit`, `offset`, `returned_count`, `total_count`, `was_truncated`, `next_offset`, and `unit` (`items` or `characters`)
- **Pagination parameters** — `limit` and `offset` on search, browse, metadata, changes, TOC, section reads, and in-act search; item limits default to 20 (max 100), section character limits default to 10,000 (max 50,000)
- **Typed `AppContext`** — Lifespan yields a frozen dataclass accessed via `ctx.request_context.lifespan_context`
- **Three domain services** — `ComparisonService`, `RelationshipService`, and `DateService` extracted from tool adapters
- **Real transport tests** — Official MCP `Client` over in-memory fixtures, real STDIO subprocess, and loopback Streamable HTTP; CI runs MCP conformance against `/mcp`
- **New dependency: `google-re2`** — Ships as prebuilt binary wheels for CPython 3.13 on Windows and manylinux; no compiler needed to install
- **`LAW_MCP_MAX_PATTERN_LENGTH`** (default 512, range 64-4096) — Out-of-range values are clamped with a startup warning instead of blocking the server
- **`LAW_MCP_FILTER_MAX_RECORDS`** (default 100, floor 1) — Limits records processed by a single `filter_results` call; operators may raise it, but very high values lengthen the synchronous scan
- **Automated release workflow** — Integrated `prepare-release` automation script, checklist, and CI/CD verification workflows

### Changed

- **Official Python MCP SDK** — Replaced FastMCP with `mcp[cli]==2.0.0` and `MCPServer[AppContext]`
- **Native structured responses** — Tools return `EnrichedResponse` objects with `outputSchema` and object `structuredContent` instead of JSON strings
- **Stateless Streamable HTTP** — HTTP transport serves `/mcp` with `stateless_http=True`; STDIO remains the default
- **`filter_results` result set size cap** — Calls on result sets larger than 100 records (`LAW_MCP_FILTER_MAX_RECORDS`) are now refused, even without a `pattern`; failures surface as `isError=true` with a text message (error category is logged server-side only). Narrow the search or raise `LAW_MCP_FILTER_MAX_RECORDS` to work around it
- **`filter_results` pattern compilation resource bounds** — Complex patterns exceeding compiled size limits or containing more than four variable range quantifiers are rejected before compilation to avoid blocking the event loop. Preflight recognizes exact RE2 POSIX tokens (`[[:name:]]` / `[[:^name:]]`)
- **`filter_results` parameter documentation** — Documents the supported RE2 regex subset, matching validation error messages
- **Client breaking change** — Clients must read `structuredContent` (`result.structured_content`) instead of `result.content` text strings
- **Protocol error reporting breaking change** — Tool failures use protocol-visible `isError=true` instead of in-body error fields

### Removed

- **FastMCP** — No FastMCP dependency or runtime APIs
- **SSE transport** — Only STDIO and stateless Streamable HTTP are supported
- **`result: string`** — Tool outputs are no longer serialized JSON strings
- **Success-envelope `error`** — Failures no longer appear as `{data, hints, error}` inside successful tool results
- **Dead exception handler in document search** — Removed an unreachable `try/except` around escaped-query compilation

### Fixed

- **HTTP client resource leak on shutdown** — Shutdown now explicitly closes the HTTP client on server exit
- **Polish error messages for invalid pagination** — Parameter validation errors for pagination report clean Polish messages
- **Upstream API error classification** — Improved classification and handling of Sejm API network errors

### Security

- **`filter_results` fixed ReDoS vulnerability** — Client-supplied patterns compile via `google-re2` linear-time matching engine; lookarounds and backreferences are rejected with a validation error
- **Streamable HTTP Host/Origin allowlist** — Enforced Host/Origin allowlist independently of bind address, preventing DNS-rebinding attacks when listening on `0.0.0.0`
